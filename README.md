# VKChatMusic

VKChatMusic — это Single Page Application (SPA), позволяющее удобно просматривать свою музыку и альбомы из ВКонтакте и массово рассылать треки в выбранные диалоги и беседы с учетом обхода API-лимитов ВКонтакте (Flood Control).

## Особенности
*   **Авторизация через vk.com:** Прямая безопасная интеграция с использованием токенов официального клиента.
*   **Умная защита от лимитов (Батчинг):** При массовой отправке треки разбиваются на пачки по 10 штук, а бэкенд выдерживает случайные плавающие паузы от 5 до 10 секунд для предотвращения временных банов аккаунта.
*   **Server-Sent Events (SSE):** Отслеживание прогресса отправки в реальном времени с помощью встроенного в Vue 3 прогресс-бара без таймаутов браузера.
*   **Отложенная отправка:** Таймер на 5 (одиночная) и 7 секунд (мультивыбор) с возможностью отмены перед физической отправкой.
*   **State Management & Lazy Load:** Состояние авторизации и выбора сохраняется в `sessionStorage`. Треки подгружаются динамически по мере скроллинга (Intersection Observer) для экономии трафика.
*   **Адаптивность:** Полная поддержка мобильных устройств.

## Архитектура проекта
*   **Frontend:** Vue 3 (Composition API), Vite, Tailwind CSS. Развернут за Nginx (с отключенным `proxy_buffering` для поддержки SSE).
*   **Backend:** Python 3.10, FastAPI, `vk_api`. Соблюдает принцип единой ответственности (SRP) — разделен на роутеры, сервисы и конфигурации.
*   **Инфраструктура:** Docker, Docker Compose.

## Установка и запуск (Docker)

1. Убедитесь, что на сервере установлены **Docker** и **Docker Compose**.
2. Склонируйте или распакуйте архив в целевую папку.
3. Перейдите в директорию `docker`:
   ```bash
   cd docker
   ```
4. Запустите сборку и старт контейнеров:
   ```bash
   docker-compose up -d --build
   ```
5. Приложение будет доступно по IP-адресу или домену вашего сервера (порт 80). Бэкенд работает внутри локальной сети Docker на порту 8000 и проксируется через Nginx (`/api/`).

## Логирование
Бэкенд автоматически создает директорию `backend/logs` и записывает туда подробную информацию об операциях API, включая `traceback` при 500-х ошибках. Ротация лог-файлов происходит ежедневно в полночь (настраивается в `core/logger.py`).

Для просмотра логов в реальном времени:
```bash
docker logs -f <имя_контейнера_backend>
# или просмотр файла:
tail -f ../backend/logs/app.log
```
